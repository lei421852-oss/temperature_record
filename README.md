# 体温记录小程序

一个极简的体温记录微信小程序：每天滚动选择即可记录体温，日期自动生成，也可**补记过去任意一天**；一键记录月经开始/结束；支持查看/修改/删除历史（创建时间精确到秒 + 每次修改都有日志）、月历视图（体温/月经标记）；一键导出温度变化曲线图片（白底）。**每个微信账号的数据相互独立。**

## 功能一览

1. **记录页（首页）**
   - 自动显示当天日期（精确到日）；**点击顶部日期可改为过去任意一天补记**（不能选未来）
   - **滚轮式滚动选择**体温：35.0 – 42.0℃，以 0.1 为单位（一格 0.1，滚动即选）
   - 初始值 = 上一次记录的体温；从没记录过则默认 **36.5℃**
   - 一天一条记录；当天已有记录时再次保存 = 更新，并自动记一条修改日志
   - **月经记录按钮**：点击记录所选日期为月经开始日，按钮变为「结束月经」；再点击记录结束日；**误操作可一键删除本次记录**
   - **账号显示**：底部提示"数据按微信账号独立保存 · 当前账号：oxYz****1234"
2. **曲线页**
   - 折线图展示体温变化；点击曲线上的点可查看对应日期与体温
   - 一键导出：生成图片（**白色背景，不再透明**）→ 系统分享菜单（可保存到相册 / 转发给微信好友）
3. **历史页**
   - **月历视图**：每个日期下方显示当日体温；未记录日期**置灰**；已记录日期**提亮**；**月经期标红**（红点）；点击已记录日期直接进入详情修改
   - **月经记录管理**：列出每次月经周期（开始 ~ 结束/至今），可一键删除（误操作纠错）
   - 下方为记录列表：按日期倒序，每条显示**创建时间（精确到秒）**
4. **详情页**
   - 展示创建时间、最后修改时间
   - 可修改体温（同样以 0.1 为单位滚动选择），保存自动记修改日志
   - **可删除该条体温记录**（连同其全部日志），用于误操作纠错
   - 完整展示该记录的**记录日志**：创建记录 + 每次修改（时间、旧值 → 新值，均精确到秒）

## 账号与数据隔离（重要）

- **机制**：三个集合（`records` / `logs` / `periods`）的权限都设为 **「仅创建者可读写」** 后，微信云端会强制：每个账号只能读写**自己创建**的数据。你和体验版成员各自的数据天然隔离，互不可见、互不影响。
- **账号标识**：部署 `login` 云函数后，首页会显示当前账号（掩码），每条新数据也会写入 `openid` 归属标记，方便日后按账号导出/管理。
- 不需要注册用户名密码——账号就是各自的微信身份。

## 部署步骤（第一次使用，约 20 分钟）

### 1. 准备账号与工具
- **注册小程序账号**（免费，个人主体即可）：打开 https://mp.weixin.qq.com → 立即注册 → 小程序 → 按提示完成。注册后进入「管理后台 → 设置 → 开发设置」，记下 **AppID**（形如 `wx1234567890abcdef`）
- **下载微信开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html （选稳定版 Stable）

### 2. 导入项目
1. 打开微信开发者工具 → 「导入项目」
2. 目录选择本文件夹；**AppID 填你自己的 AppID**（不要用测试号，云开发必须真实 AppID）
3. 导入后工具会自动编译

### 3. 开通云开发
1. 点击工具栏「云开发」按钮 → 开通 → 创建环境（环境名随意，如 `temp-dev`，免费额度即可）
2. 在「云开发控制台 → 设置」里复制**环境 ID**（形如 `temp-dev-1a2b3c`）

### 4. 配置环境 ID
打开 `miniprogram/config.js`，把 `envId` 改成你的环境 ID：

```js
const envId = 'temp-dev-1a2b3c'   // ← 改成你自己的
```

> 如果只创建了一个环境，也可以留空字符串，会使用默认环境。

### 5. 创建数据库集合
1. 开发者工具 → 工具栏「云开发」→ 数据库
2. 依次新建**三个集合**：`records`（体温记录）、`logs`（日志）、`periods`（月经周期）
3. 三个集合的权限都设为 **「仅创建者可读写」** ← 这是**账号数据相互独立**的关键

### 6. 部署 login 云函数（账号显示）
1. 开发者工具左侧「资源管理器」→ 展开 `cloudfunctions` → 右键 **login** 文件夹
2. 选择 **「上传并部署：云端安装依赖」**，等待部署完成
3. 部署后首页会显示"当前账号：oxYz****1234"；不部署也不影响体温记录（只不显示账号）

### 7. 编译预览
- 工具中点击「编译」，首页应显示今日日期 + 体温滚轮 + 月经按钮 + 账号信息
- 点「预览」生成二维码，手机微信扫码即可使用

### 8. 给第二个人使用（体验版，免审核）
1. 开发者工具 → 右上角「上传」→ 填版本号与备注
2. 登录微信公众平台 → 管理 → 版本管理 → 将刚上传的版本设为**体验版**
3. 成员管理 → 添加「体验成员」（对方微信号）
4. 对方在微信里打开你的小程序即可使用。**对方的数据和你完全独立**：他只能看到自己记录的体温和月经数据

## 使用说明

- **每天记录**：打开小程序 → 上下滚动滚轮选到今天的体温 → 保存。滚轮初始位置自动是上一次的体温，基本只需微调
- **补记**：首页点击顶部日期 → 选择过去的某一天 → 滚动选择体温 → 保存（按钮显示「补记该日」）；月经开始/结束同样按所选日期记录
- **月经记录**：首页点「记录月经开始」→ 按钮变为「结束月经」→ 再次点击记录结束日；误操作时点「误点？删除本次」撤销
- **修改**：历史记录 → 点任意一天（月历或列表）→ 滚动选择新体温 → 保存修改；每次修改自动生成一条修改日志
- **删除**：体温记录 → 详情页底部「删除这条记录」（连同日志一起删除）；月经记录 → 历史页「月经记录」卡片中删除（均有确认提示）
- **看曲线**：首页 → 温度曲线 → 导出温度曲线（白底图片），即可保存图片或分享给医生/家人
- **数据归属**：数据存在云开发数据库，按微信账号隔离；换手机、重装小程序都不丢

## 测试时提示「请检查云开发环境配置」怎么办

> 程序现在会在弹窗里同时显示**原始错误**，按下面的对照表即可定位原因。

按出现频率排序的排查清单：

1. **用的是测试号/游客 AppID（最常见）**：`project.config.json` 里 appid 若是 `touristappid`，云开发必然不可用。导入项目时选择**你自己注册的真实 AppID**（或在工具右上角「详情 → 基本信息」里修改）。
2. **未开通云开发**：工具栏没有「云开发」按钮 → 点击开通并创建环境（免费额度即可）。
3. **环境 ID 没填或填错**：把 `miniprogram/config.js` 的 `envId` 改成云开发控制台里的环境 ID。
4. **集合没建**：云开发控制台 → 数据库 → 新建 `records`、`logs`、`periods` 三个集合。
5. **工具未登录**：开发者工具右上角登录微信账号。
6. **基础库版本过低**：「详情 → 本地设置」→ 调试基础库选 2.2.3 以上。

原始错误与解决办法对照：

| 弹窗里的原始错误（关键片段） | 解决办法 |
|---|---|
| `没有权限，请先开通云开发或云托管` | 当前 AppID 未开通云开发：工具顶部「云开发」按钮 → 开通 → 创建环境（确认用的是真实 AppID） |
| `invalid scope` 或错误码 `-501000` | 真实 AppID + 已开通云开发（第 1、2 条） |
| `env not exist` / `invalid env` | 核对 `config.js` 的 envId（第 3 条） |
| `collection not exist` 或 `-502005` | 创建 `records`、`logs`、`periods` 三个集合（第 4 条） |
| `login has not been called` 等未登录 | 工具右上角登录（第 5 条） |
| `permission denied` | 检查集合权限，建议「仅创建者可读写」 |

## 常见问题

| 问题 | 解决 |
|---|---|
| 编译报错/加载失败提示云开发 | 见上方「测试时提示请检查云开发环境配置怎么办」排查清单 |
| 页面空白、数据为空 | 确认集合名是 `records`、`logs`、`periods`，权限为「仅创建者可读写」 |
| 历史页月历不显示 | 先「清除缓存 → 全部清除」再重新编译；打开调试器 Console 看红色报错并告诉我；确认已创建 `records` 集合（读取失败会弹窗说明原因，月历此时仍会渲染为空日历） |
| 首页显示"未获取到账号信息" | 未部署 login 云函数：cloudfunctions/login 右键 →「上传并部署：云端安装依赖」 |
| 月经按钮点了没反应 | 确认已创建 `periods` 集合；操作失败时弹窗会显示原始错误 |
| 删除记录后数据还在？ | 删除走云数据库（records 记录 + 对应 logs 日志 / periods 月经记录），刷新页面即生效；若提示权限错误请检查集合权限 |
| 导出图片失败或提示无权限 | 在设置里允许「保存到相册」；新版微信会直接弹系统分享菜单，也可在那里保存 |
| 想备份数据 | 云开发控制台 → 数据库 → 每个集合右上角可导出 JSON |
| 两个人的数据会不会互相影响？ | 不会：集合权限「仅创建者可读写」由云端强制，每个账号只能读写自己的数据 |

## 后续扩展建议（已留好扩展点）

- **复杂逻辑上云函数**：所有数据操作集中在 `miniprogram/utils/db.js`，以后可平滑迁移到 `cloudfunctions/` 下的云函数（如数据校验、统计、定时任务）
- **多用户对比**：权限放开后可按 `openid` 分组做家人体温对比
- **症状/用药记录、周报月报、导出 PDF 给医生**
- **月经周期统计**：根据 periods 数据计算平均周期长度、预测下次月经时间；结合体温曲线提示排卵期
- **异常提醒**：云函数定时检查 + 微信订阅消息推送
- **图表增强**：当前曲线用原生 Canvas 自绘（零依赖），如需缩放、图例等高级交互可替换为 ECharts 小程序版
